Cybersecurity

Defending the digital frontier.

My cybersecurity journey started with a simple question: "How would someone break this?" That question changed everything. Now, I approach every project with a defender's mindset — identifying attack surfaces, hardening systems, and building security in from the ground up, not bolting it on after.

Offensive

Penetration Testing

Simulating real-world attacks to find vulnerabilities before malicious actors do. Web apps, APIs, and network infrastructure.

Defensive

Secure Code Review

Auditing codebases for injection flaws, authentication bypasses, and misconfigurations that leave systems exposed.

Training

Security Awareness

Teaching developers to write secure code by default — because the cheapest vulnerability to fix is the one never introduced.

Research

CTF & Vulnerability Research

Actively participating in Capture The Flag challenges and researching emerging threat vectors to stay ahead of the curve.
